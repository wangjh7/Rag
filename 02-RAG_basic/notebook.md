# 1. 向量和形状
embedding模型会把一段文字变成一串数字，比如：
```python
"今天天气很好"  →  [0.12, -0.53, 0.08, ..., 0.31]   # 假设共 384 个数字
```

这串数字就是**向量**，数字的个数 d 叫**维度**（不同模型不同，常见 384、768、1024）。
在 numpy 里，这样的一串数字是一个 **数组**（`np.ndarray`）。数组有个重要属性叫**形状**（**shape**），描述它有几行几列：


| 数组 | 形状 | 直观理解 |
| ---- | ---- | ---- |
| [0.1, 0.2, 0.3] | (3,) | 一维：一串数字，只有"长度" |
| [[0.1, 0.2, 0.3]] | (1, 3) | 二维：1 行 3 列，像只有一行的表格 |
| [[...], [...], [...]] | (3, 3) | 二维：3 行 3 列 |


注意 `(3,)` 和 `(1, 3)` 是不同的：前者是一条线，后者是只有一行的表格。

## 编码文档
```python
doc_vecs = model.encode(corpus, normalize_embeddings=True)
```
假设 corpus 有 3 篇文档：
```python
corpus = ["猫喜欢吃鱼", "今天下雨了", "狗喜欢玩球"]
```
`model.encode` 对每篇文档各生成一个向量，然后叠起来变成一个二维数组，每一行对应一篇文档：
```
doc_vecs =
[[0.2, 0.5, ...],    ← "猫喜欢吃鱼" 的向量
 [0.7, -0.1, ...],   ← "今天下雨了" 的向量
 [0.3, 0.4, ...]]    ← "狗喜欢玩球" 的向量
```
形状是 `(3, d)`，也就是 `(N, d)`：N=3 篇文档，每篇 d 个数字。

## 什么是归一化
`normalize_embeddings=True` 的意思是：把每个向量**缩放到长度为 1**，方向保持不变。
向量的"长度"是各元素平方和再开根号。比如 `[3, 4]` 的长度是 √(9+16) = 5，归一化就是每个数都除以 5，得到 `[0.6, 0.8]`，验证一下：√(0.36+0.64) = 1。
为什么要这样做？因为这样后面只用一个简单的乘法就能得到余弦相似度。

# 2. 矩阵乘法
```python
scores = doc_vecs @ q_vec
```
`@` 是矩阵乘法。当左边是 `(N, d)`、右边是 `(d,)` 时，规则很简单：**左边的每一行，和右边那一串数字，对应位置相乘再求和**（这个操作叫"点积"）。

用一个小例子，假设 d=2，有 3 篇文档：
```
doc_vecs = [[0.6, 0.8],     ← 文档0
            [1.0, 0.0],     ← 文档1
            [0.0, 1.0]]     ← 文档2

q_vec = [0.6, 0.8]
```
逐行算：
```
文档0: 0.6×0.6 + 0.8×0.8 = 0.36 + 0.64 = 1.00
文档1: 1.0×0.6 + 0.0×0.8 = 0.60
文档2: 0.0×0.6 + 1.0×0.8 = 0.80
```
结果：
```
scores = [1.00, 0.60, 0.80]     形状 (3,)
```
也就是 `(N, d) @ (d,) → (N,)`：每篇文档得到一个分数。

## 为什么点积等于余弦相似度
余弦相似度衡量的是两个向量的方向有多接近，公式是：
```
cos = 点积 / (长度A × 长度B)
```
如果两个向量长度都是 1（也就是归一化过的），分母就是 1×1=1，公式变成：
```
cos = 点积
```
所以做归一化，就是为了让这里可以直接用点积，省掉除法。

分数的含义：越接近 1，方向越一致，语义越相近；接近 0 表示基本无关；负数表示方向相反。
